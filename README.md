🛒 Lembre e Comprei
Lembre e Comprei é uma aplicação web simples e prática para criar e organizar listas de compras. Com uma interface intuitiva, permite adicionar itens, visualizar data e hora da adição e marcar o que já foi comprado.

🚀 Funcionalidades
Adição de itens à lista

Validação para não inserir itens vazios

Marcação de itens como comprados (com risco no texto)

Exibição da data e hora de cada item adicionado

Mensagem automática quando a lista estiver vazia

🖥️ Tecnologias
HTML5

CSS3

JavaScript (Vanilla)
